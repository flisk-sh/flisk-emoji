# Flisk green thunder <img src="https://raw.githubusercontent.com/flisk-sh/flisk-emoji/main/png/flisk-thunder-64.png" width="28" alt="flisk emoji">

The Flisk bolt as a custom emoji. It is an image, not a Unicode character, so it works wherever you can paste or upload an image.

## Use it in 10 seconds

**GitHub issues, PRs, READMEs** (renders as a small inline emoji): paste this.

```md
<img src="https://raw.githubusercontent.com/flisk-sh/flisk-emoji/main/png/flisk-thunder-64.png" width="20" alt="flisk">
```

Result: <img src="https://raw.githubusercontent.com/flisk-sh/flisk-emoji/main/png/flisk-thunder-64.png" width="20" alt="flisk"> Flisk is live.

**Slack:** download [flisk-thunder-128.png](https://raw.githubusercontent.com/flisk-sh/flisk-emoji/main/png/flisk-thunder-128.png), then Customize workspace, Emoji, Add custom emoji, name it `flisk`. Type `:flisk:` after that.

**Discord:** Server settings, Emoji, Upload emoji, the same 128 px file. Type `:flisk:`.

**Telegram:** send the [512 px file](https://raw.githubusercontent.com/flisk-sh/flisk-emoji/main/png/flisk-thunder-512.png) to @Stickers.

**Anywhere else:** right-click the big image above, Copy image, paste.
