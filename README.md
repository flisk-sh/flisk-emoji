# Flisk green thunder

The Flisk bolt as a custom emoji. Use it in Slack, Discord, Telegram, GitHub comments or anywhere that takes an image.

| File | Use |
|---|---|
| `flisk-thunder.svg` | Source, scales to any size |
| `png/flisk-thunder-512.png` | Telegram stickers, large avatars |
| `png/flisk-thunder-128.png` | Slack and Discord custom emoji (name it `:flisk:`) |
| `png/flisk-thunder-64.png`, `-32.png` | Inline and small UI |

This is an image, not a Unicode character. Unicode does not accept brand logos, so the bolt cannot become a built-in emoji.

Slack: Customize workspace, Emoji, Add custom emoji, upload the 128 px file.
Discord: Server settings, Emoji, Upload emoji, the 128 px file.
